# Lexique multilingue de SeldonH : repérage des mots-clés d'une question posée en anglais, espagnol, italien ou
# allemand. Avant de choisir les fiches et de lancer les détecteurs (phases, modèle, dessin, méthodes de datation…),
# SeldonH remplace dans la question chaque terme listé à droite par le terme français de gauche. Le modèle de langage
# reçoit toujours la question d'origine et répond dans sa langue.
#
# Format : terme français = équivalent, équivalent, …   (minuscules ou non, accents indifférents)
# « mot* » : tout mot qui commence par « mot » (utile pour l'allemand : Phasen*, Kalibrier*…).
# Une expression de plusieurs mots est reconnue telle quelle. L'utilisateur peut compléter ce lexique avec un fichier
# « lexique.txt » dans son dossier de compétences (même format, lu après celui-ci).
